# 축구분석기.html — 파일 하나로 끝

브라우저로 **더블클릭**하면 됩니다. 서버도, 프록시도, 배치 파일도, 설치도 없습니다.

## 왜 이렇게 되나

그동안 프록시·파이썬·PowerShell 서버를 만든 이유는 **football-data.org 하나**
때문이었습니다. 그 API는 브라우저가 직접 부르면 막습니다(CORS).

그런데 그 소스가 주는 리그 9개는 **API-Football이 같은 ID로 이미 전부 제공합니다.**
추가로 얻는 리그가 하나도 없습니다. 그래서 이 판에서는 그 소스를 화면에서 아예
치웠고, 그 순간 서버가 필요 없어졌습니다.

| 소스 | 커버리지 | 키 |
|---|---|---|
| API-Football | 30개 리그 전부 (K리그·J리그·MLS 포함) | 필요 |
| OpenLigaDB | 분데스리가 · 2.분데스리가 | 불필요 |
| TheSportsDB | 보조 | 불필요 |

**API-Football 키 하나면 끝입니다.**

## 쓰는 법

1. `축구분석기.html` 을 더블클릭
2. API-Football 키를 넣고 `이 브라우저에 키를 기억시키기` 체크
3. 팀 이름을 넣고 분석

키는 그 브라우저 안에만 남습니다(localStorage). 체크를 끄면 지워집니다.

## 다시 만들기

```
python3 make.py            # 축구분석기.html
```

원본 `../sports-ai-analyzer-v4.html` 은 건드리지 않습니다. 화면을 고치려면
원본을 고치고 위 명령을 다시 돌리면 됩니다.

`standalone.js` 가 하는 일은 세 가지뿐입니다 — 브라우저에서 못 쓰는 소스 치우기,
키 기억, 안내 문구를 사실에 맞게 고치기.
