미실행
MODEL GOVERNANCE · LITE MODE
데이터 계층과 계산 원칙
⚡ LITE MODE: 일괄 분석은 팀 폼과 슈팅 통계 두 계층만 조회합니다. 경기당 호출 = 팀 검색(2, ID 캐시되면 0) + fixture(1) + 폼(2) + 슈팅(슈팅표본×2).
폼층: 최근 N경기의 득점·실점·승점을 최신 경기에 더 높은 가중치(0.9^i)를 주어 계산.
슈팅층: 최근 경기의 슈팅 수 · 유효슈팅 평균.
자동 대체 소스: API-Football이 실패하면 TheSportsDB로 자동 전환합니다. 슈팅 통계는 제공되지 않으므로 신뢰도 계산에서 제외되고(감점이 아님), 대신 소스 신뢰도 계수 0.85가 곱해집니다.
데이터 부족 시: 폼 득실점이 하나라도 없으면 예상득점을 추정하지 않고 해당 경기를 "데이터 부족"으로 표시합니다. 0으로 대체해 억지로 계산하지 않습니다.
순서 보존: 결과 카드는 신뢰도순으로 정렬되지만, 각 카드와 브리핑은 항상 원래 입력 슬롯 번호(MATCH n)를 표시합니다.
