축구 분석기 - 쉬운 실행 방법
==========================================

준비물은 파일 2개뿐입니다.

    1) 분석기-실행.bat
    2) sports-ai-analyzer-v4.html

프록시 파일(fd-proxy.js)은 이제 따로 받지 않아도 됩니다.
분석기-실행.bat 안에 들어 있어서, 필요할 때 알아서 꺼내 씁니다.


------------------------------------------
1단계.  폴더 하나 만들기
------------------------------------------
바탕화면에서 마우스 오른쪽 클릭 -> 새로 만들기 -> 폴더
이름은 아무거나 (예: 축구분석기)


------------------------------------------
2단계.  파일 2개를 그 폴더에 넣기
------------------------------------------
받은 파일 2개를 방금 만든 폴더 안으로 끌어다 놓으세요.
파일 이름 뒤에 (1) 같은 게 붙어 있어도 그대로 두면 됩니다.
알아서 찾습니다.


------------------------------------------
3단계.  분석기-실행.bat 더블클릭
------------------------------------------
검은 창이 하나 뜨고, 이런 순서로 지나갑니다.

    [1/3] 프록시를 켭니다  (node)
    [2/3] 준비될 때까지 3초 기다립니다
    [3/3] 분석기를 엽니다

브라우저가 저절로 열립니다.
검은 창은 그대로 두세요. 닫으면 프록시도 같이 꺼집니다.


------------------------------------------
4단계.  확인
------------------------------------------
분석기 위쪽 "프록시" 칸을 보세요.
아무것도 입력하지 않아도 이런 줄이 떠 있으면 성공입니다.

    프록시를 자동으로 찾았습니다 - http://127.0.0.1:8787

여기까지 되면 끝입니다. 팀 이름을 넣고 분석하면 됩니다.


------------------------------------------
끄는 방법
------------------------------------------
작업표시줄의 [fd-proxy] 창을 닫으면 됩니다.
브라우저는 그냥 닫으면 됩니다.


==========================================
잘 안 될 때
==========================================

* "프록시를 띄울 수 없습니다" 라고 나온다
  -> Node.js 도 Python 도 없는 상태입니다.
     검은 창에서 아래를 직접 쳐 보세요.
         node -v
         python --version
     둘 다 오류가 나면 https://nodejs.org 에서 LTS 를 설치하세요.

* 검은 창이 번쩍하고 바로 닫힌다
  -> 폴더 주소창에 cmd 를 치고 엔터를 눌러 명령 창을 연 다음,
     거기에 분석기-실행.bat 을 쳐서 실행하면 내용이 남습니다.

* 분석기 HTML 을 못 찾는다고 나온다
  -> HTML 파일이 같은 폴더에 없는 것입니다. 2단계를 다시 보세요.


==========================================
참고 - 프록시는 사실 선택 사항입니다
==========================================
프록시는 football-data.org 한 곳을 쓰기 위한 것입니다.
그 칸을 비워 두어도 분석기는 정상 동작합니다.

    API-Football   - football-data.org 가 다루는 9개 리그를 모두 덮습니다
    OpenLigaDB     - 분데스리가, 키 없이 동작
    TheSportsDB    - 나머지 리그 보조

번거로우면 프록시는 건너뛰고 API-Football 키만 넣어 쓰셔도 됩니다.
